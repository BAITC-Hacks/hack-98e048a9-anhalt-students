             Контекст и проблема отрасли
          

          
Вызов Самрук-Қазына: Шелекский ветровой коридор

          

            

              
 Волатильность ветра

              
Шелекский коридор зажат между Заилийским Алатау и хребтом Кетмень. Резкие перепады ветра достигают 15–20 м/с за считанные часы.

            

            

              
 Небалансы KEGOC

              
На Балансирующем рынке электроэнергии (БРЭ) отклонение факта от суточного плана влечет покупку мощности по штрафным тарифам.

            

            

              
 Штормовой износ

              
Внезапные штормовые ветра (≥ 25 м/с) вызывают аварийные отключения и механические перегрузки лопастей и редукторов турбин.

            

          

          

            Цель проекта: Создать детерминированный Agentic AI для автономного почасового прогнозирования выработки двух турбин ВЭС на 24–48 часов без утечки будущих данных и с защитой от штормов.
          

        


        
        

          

             Архитектура системы
          

          
Двухуровневый Physics-Informed Agentic Loop

          

            

              
 Уровень 1: Аэродинамическая физика

              
    
                
  • Плотность воздуха: ρ = P / (287.058 × T) — зимой плотность в Шелеке на 10–12% выше, увеличивая кинетическую энергию E ~ ρ v³.
    • 
                
  • Сдвиг ветра Хеллмана: Экстраполяция с 10 м на ступицу 100 м (v₁₀₀ = v₁₀ × 10^α).
    • 
                
  • МЭК 61400-12: Сигмоидальная кубическая кривая мощности с отсечками 3.0 и 25.0 м/с.
    • 
              

            

            

              
 Уровень 2: Machine Learning & Agent Loop

              
    
                
  • LightGBM Regressor: Обучение на физических признаках с изоляцией истории строго до момента выпуска (cutoff ≤ 2026-02-01).
    • 
                
  • Safe Fallback: При любых сбоях ML агент мгновенно переключается на чистую физическую модель.
    • 
                
  • Штормовой фильтр: При v ≥ 25 м/с выработка жестко приравнивается к 0 МВт.
    • 
              

            

          

          

            Agent Loop: Plan → Retrieve (Open-Meteo m/s) → Verify Hash → Physics Features → ML Forecast → Storm Cutout Revise → Audit (RU/KZ)

             Надежность и Data Governance
          

          
Транзакционная загрузка SCADA и Честный Аудит

          

            

              
 Транзакционный откат (Candidate Trial)

              
Любой загружаемый CSV проходит предварительное пробное обучение на изолированном экземпляре модели. При любых дефектах структуры или недостатке строк (менее 10) возвращается HTTP 422, а рабочая база и модель остаются на 100% неповрежденными.

            

            

              
 Честность источников (Provenance)

              
Мы не рисуем фиктивные метрики: без подтвержденных фактических актов выработки Skill Score честно возвращается как null. Демонстрационный набор маркируется SYNTHETIC_DEMO, а пользовательский файл — USER_SUPPLIED_UNVERIFIED.

            

          

          

            Автоматическая верификация кодовой базы:
            Все автоматические тесты PASSED (100%)
          

        


        
        

          

             Экономика и масштабирование
          

          
Ценность для АО «Самрук-Қазына»

          

            

              
 Минимизация небалансов

              
Точное суточное планирование снижает необходимость покупки балансирующей электроэнергии у системного оператора KEGOC в часы пиковых отклонений.

            

            

              
 Защита активов ВЭС

              
Диспетчерский модуль своевременно предупреждает о штормовых порывах и обледенении лопастей, продлевая ресурс ветроустановок.

            

            

              
 Масштабируемость

              
Готовность к тиражированию на Ерейментаускую ВЭС (50 МВт), расширение Шелекского узла (60 МВт) и ветропарк в Хромтау.

            

          

          

            Готовность к интеграции: Параметризованный REST API (FastAPI / ASGI) и CSV-экспорт; в дорожной карте развития — контейнеризация Docker и подключение промышленных SCADA-протоколов (Modbus TCP/OPC-UA).
